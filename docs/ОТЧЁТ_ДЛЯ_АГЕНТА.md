## 2. Окружение и сборка

- Игра: `C:\Program Files (x86)\Steam\steamapps\common\DARK SOULS REMASTERED`, ModEngine2 в `ModEngine2\`.
- Проект (git): `ModEngine2\DarkSoulsReforged\`. Готовый мод ставится в `ModEngine2\FirelinkHub\`
  (имя папки в конфиге — FirelinkHub; переименование в Reforged = правка конфига, это решает автор).
- Сборка: `cd work`, `python build.py` (по умолчанию с меню отладки; `--release` — без него),
  `python audit.py` (должно быть `problems: 0`), `python install.py`.
- Не в репозитории (нужно для сборки): `work/orig/` (ванильные GameParam, paramdef, msg),
  `tools_dl/` (esdtool 0.5.1, zig 0.16 для DLL, иконки DS2/DS3, DSR Gadget 1.6).
- Кооператив: Seamless Co-op. Сейвы мода в кооперативе — `DRAKS0005.<расширение>` (сейчас `test2`).
  Настройки Seamless автора: `boss_health_scaling = 200` (по умолчанию 100), `enemy_health_scaling = 75`
  (по умолчанию 35), `boss_posture_scaling = 60`. Это решение автора; влияет на баланс боссов в коопе.
- Слотов сохранения больше 10 сделать нельзя (формат сейва). Обходной путь — другое расширение в Seamless
  (своё на каждый набор из 10 слотов) или скрипт-переключатель наборов (предлагался, не делался).

## 4. Обсуждалось только в чате (нет в GDD)

Сверено с полными записями всех сессий (16–20.10.2026), не по памяти.

### С чего всё началось
- Две идеи автора: (1) лечение союзников заклинаниями, как в DS2/DS3/Elden Ring; (2) «Храм Огня как
  Маджула»: мини-квесты NPC, переезд NPC в Храм, новые торговцы, полезные ограниченные расходники,
  камни жизни из DS2.
- **AllyHeal — отдельный опубликованный мод** (публичный репозиторий `IHitawI/AllyHeal`, баннер, релиз,
  текст для Nexus). Heal, Great Heal, Excerpt, Replenishment лечат союзников в радиусе 3 м на 75% (автор
  попросил поднять с 60%), групповые баффы — только союзникам. В Seamless в режиме PvP союзников не лечит
  (так и задумано; автор сначала принял это за баг). Мод FirelinkHub/Reforged заменяет AllyHeal (оба
  подменяют GameParam) и включает его код (`work/allyheal.py`).
- Предупреждение, данное в начале: с изменёнными параметрами на официальных серверах DSR есть риск
  софт-бана; мод — для игры в закрытой компании с одинаковыми файлами.

### Ранние решения по составу мода (16.10)
- Баффы оружия на союзников — **[отклонено]**.
- «Бесполезные предметы с пользой»: Талисман Ллойда (зона +20% урона по врагам), Навозный пирог (не травит
  бросающего), Мусор (метательный, отвлекает). Подвеска стала ключом квеста (→ Камень перерождения).
- **Ремонт кристального оружия:** только у кузнеца (Андре), дорого, цена по оружию; порошок и заклинание
  «Починка» чинить его **не должны**; запрет `disableRepair` снимать нельзя в лоб — нужен эксперимент,
  блокирует ли он все способы сразу. Позже автор: у Андре два мини-квеста — переезд в Храм (сделано: за
  Большой уголёк) и «предметный» = ремонт кристального оружия. **[обсуждено, не начато]**
- Иконки — из DS2 с вики (у автора DS2 не установлен; скачивание с разрешения). Сделано для камней, трав,
  осколка, камня перерождения; иконки заклинаний — свои (знак с вики на фоне школы DS1).
- Варпы со старта — не нужны; **респек — нужен** (сделан: Камень перерождения → Анастасия).
