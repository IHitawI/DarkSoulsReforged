## 1. Правила работы с автором (обязательны)

Это договорённости из чата, нарушать нельзя.

- **Язык общения — только русский.** Тексты мода: русский, в остальных языках игры — английский.
- **Не задавать вопросы вида «проверь, пожалуйста».** Автор проверяет всё сам пачкой. Всё, что требует проверки
  в игре, дописывается в `ПРОВЕРКА.md`. Замечания из прохождений — в `ЗАМЕЧАНИЯ.md`.
- **Конфиг ModEngine2 (`config_darksoulsremastered.toml`) не трогать** — автор правит его сам. Настройки
  Seamless Co-op (`SeamlessCoop/ds1sc_settings.ini`) менять только по прямой просьбе (один раз было:
  `save_file_extension = test2`, копия прежних настроек — `ds1sc_settings.ini.bak_co2`).
- **Скачивание чего угодно — только с явного разрешения.**
- **Пуш на GitHub — только с разрешения**, каждый раз отдельно. Репозиторий публичный.
- **Не пересобирать мод посреди сессии кооператива**: у автора и напарника файлы должны совпадать.
  После сборки сборку нужно отдать напарнику целиком. DLL не пересобирается, пока игра запущена (файл занят).
- Ранние варпы (до Сосуда Повелителя) — **[отклонено]** автором. В меню отладки телепорт есть — это только
  для тестов.
- База мода — ванильные параметры (не PrepareToDieAgain / DSExtended). Групповые баффы действуют только на
  союзников, никогда на соперников в PvP. Баффы оружия на союзников — **[отклонено]**.
- Автор пишет резко и коротко; отвечать по делу, без лишних вопросов, с конкретикой «что сделано / что
  проверить».

## 2. Окружение и сборка

- Игра: `C:\Program Files (x86)\Steam\steamapps\common\DARK SOULS REMASTERED`, ModEngine2 в `ModEngine2\`.
- Проект (git): `ModEngine2\DarkSoulsReforged\`. Готовый мод ставится в `ModEngine2\FirelinkHub\`
  (имя папки в конфиге — FirelinkHub; переименование в Reforged = правка конфига, это решает автор).
- Сборка: `cd work`, `python build.py` (по умолчанию с меню отладки; `--release` — без него),
  `python audit.py` (должно быть `problems: 0`), `python install.py`.
- Не в репозитории (нужно для сборки): `work/orig/` (ванильные GameParam, paramdef, msg),
  `tools_dl/` (esdtool 0.5.1, zig 0.16 для DLL, иконки DS2/DS3, DSR Gadget 1.6).
- Кооператив: Seamless Co-op. Сейвы мода в кооперативе — `DRAKS0005.<расширение>` (сейчас `test2`).
  Настройки Seamless автора: `boss_health_scaling = 200` (по умолчанию 100), `enemy_health_scaling = 75`
  (по умолчанию 35), `boss_posture_scaling = 60`. Это решение автора; влияет на баланс боссов в коопе.
- Слотов сохранения больше 10 сделать нельзя (формат сейва). Обходной путь — другое расширение в Seamless
  (своё на каждый набор из 10 слотов) или скрипт-переключатель наборов (предлагался, не делался).

**DLL (`work/dll/firelinkhub.c`)**: пишет в `ModEngine2\FirelinkHub\firelinkhub.log`.
- GameDataMan / ChrClassBase: сигнатура `48 8B 05 ? ? ? ? 48 85 C0 ? ? F3 0F 58 80 AC 00 00 00`.
- Флаги: сигнатура `48 8B 0D ? ? ? ? 99 33 C2 45 33 C0 2B C2 8D 50 F6`, раскладка как в DSR Gadget
  (группа/область/секция; 0x500 байт на область, 128 на секцию).
- Последний костёр: `ChrClassWarp` (`48 8B 05 ? ? ? ? 66 0F 7F 80 …`) + смещение, вычисленное из кода игры
  (в текущей версии 0xB34); значение = точка появления костра (сущность костра + 1000).

  вызов `(GameDataMan, 1)`.
- PlayerGameData = *(GameDataMan + 0x10); статы через 8 байт с +0x40; MagicData = *(PGD + 0x418).
- Ключ шифрования сейва DSR (AES-128-CBC, для чтения сейва при отладке):
  `01 23 45 67 89 AB CD EF FE DC BA 98 76 54 32 10`. В сейве: статы с 0x90 (по 8 байт), настроенные
  заклинания — список {id, заряды}.

**Уроки:**
- Скрипт карты `2003[14]` (смена карты) в игре используется только внутри одной карты.
- Выход из меню костра перед своим переносом — через L1 (встать от костра), не через L12.
- Подменю в диалоге: сначала `CloseShopMessage()`, иначе списки рисуются друг на друге.
- `ChangePlayerStat` не пересчитывает HP, выносливость и ячейки заклинаний.
- Флаги нельзя выставлять пачкой из открытого меню костра — софтлок; делать через событие.
- Враг, перенесённый в другую карту, требует свой `*_battle.lua` в luabnd этой карты (иначе стоит).
- Вершины навмеша локальны к части карты; у Сада Тёмных корней две MSB на один скрипт.
- Номера диалогов копий NPC в одной карте должны быть разными; ванильные события смерти NPC 11020510/11020530
  на копиях не использовать (превращали NPC в труп с вещами).
- Перекраска текстур через `normalChangeTexChrId` в игре не показалась.
- В heredoc bash теряются обратные слэши — строки с `\n` писать через редактор файлов или `chr(10)`.
